# Mentoria — versão preservada

Arquivada em 06/10/2026 por solicitação do cliente. A oferta pública passa a apresentar encontros presenciais para empresas.

- `pagina-original.html`: conteúdo e estrutura integrais da página anterior.
- `secao-original.html`: seção original da página inicial.
- Imagem preservada em `dist/assets/mentoria-ilustrativa.webp`; componentes e estilos existentes mantidos.

A mentoria pode ser retomada a partir destes arquivos e do histórico Git. Os arquivos deste diretório não entram na publicação de homologação.

A chave interna `mentoria` continua como identificador técnico do percurso empresarial no formulário para preservar a compatibilidade com o backend existente. Os textos apresentados ao visitante descrevem o encontro presencial. Não há agendamento automático: data e local serão combinados com a equipe.
